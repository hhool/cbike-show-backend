  Vercel 部署检查清单 — site-backend
═══════════════════════════════════════════════════════════════════════════

前置准备（本地）
✅ npm install
✅ 测试 PostgreSQL: DATABASE_URL="postgresql://..." npm run dev
✅ 测试管理员面板: http://localhost:3000/admin

GitHub 推送
✅ git add .
✅ git commit -m "chore: configure Vercel deployment with PostgreSQL"
✅ git push origin main

Vercel 配置
✅ 访问 https://vercel.com/dashboard
✅ New Project → Import from GitHub
✅ 选择 cbike_show/site-backend 仓库
✅ 在 "Environment Variables" 中配置以下变量：

必须配置（复制自 .env.production.example）:
  - NODE_ENV=production
  - VERCEL=true
  - PAYLOAD_SECRET=<generate: openssl rand -base64 32>
  - NEXTAUTH_SECRET=<generate: openssl rand -base64 32>
  - AUTH_SECRET=<same as NEXTAUTH_SECRET>
  - NEXTAUTH_URL=<your-vercel-domain>
  - NEXT_PUBLIC_SITE_URL=<your-vercel-domain>
  - NEXT_PUBLIC_API_BASE_URL=<your-vercel-domain>
  - DATABASE_URL=<your-neon-postgres-url>
  - CORS_ORIGINS=https://cbike-show-front.vercel.app,<your-vercel-domain>

可选配置:
  - SMTP_HOST, SMTP_USER, SMTP_PASS (邮件验证)
  - R2_ACCOUNT_ID, R2_BUCKET_NAME 等 (文件存储)
  - SEED_ADMIN_EMAIL, SEED_ADMIN_PASSWORD (初始账户)

部署与首次初始化
✅ 点击 Deploy
✅ 等待构建完成 (约 2-3 分钟)
✅ 部署成功后，运行首次数据库迁移:
   vercel env pull
   npm run db:migrate:fresh
✅ 访问 https://<your-project>.vercel.app/admin 验证

验证清单
□ Admin 面板可访问
□ 登录功能正常
□ 能够创建新闻条目
□ 图片上传正常
□ 数据库连接稳定

问题排查
如果部署失败:
  • 检查 DATABASE_URL 是否正确
  • 检查 PAYLOAD_SECRET 长度是否 ≥ 32 字符
  • 查看 Vercel Logs (Deployments → Build Logs)
